✨ 项目简介

基于 HTML5 + CSS3 + JavaScript + Vue 2.6 开发的多页面静态花卉模拟电商网站。



\- 独立完成需求规划与页面结构设计：信息架构梳理、页面跳转流程设计、内容策划（花卉分类体系、养护知识体系）

\- AI 协作开发：页面布局与部分交互代码借助 AI 辅助生成，本人负责提示词设计、代码调试、BUG 修复、样式调整与功能验证

\- 纯前端演示项目，购物车、用户表单相关信息全部使用浏览器 localStorage 本地存储，没有后端服务与数据库



📖 功能清单

\- 首页花卉展示、花卉分类页面、花卉详情页

\- 养护指南、关于我们介绍页面

\- 登录 / 注册 / 找回密码表单页面

\- 购物车模块（Vue 2.6实现）：商品增删改数量、库存校验、优惠码折扣计算、订单金额自动汇总

\- 加入购物车，导航栏购物车数量角标跨页面同步更新

\- 图片加载失败兜底占位图，防止图片裂开

\- 响应式布局（Flex + Grid），同时适配电脑与移动端设备



🛠 技术栈

HTML5 ｜ CSS3 ｜ JavaScript ｜ Vue 2.6 ｜ LocalStorage ｜ Flex + Grid 布局



🚀 本地运行

1\. 进入 `Public` 文件夹

2\. 直接双击 `index.html` 在浏览器打开，\*\*不需要启动服务器，断网也可以完整运行\*\*

> 购物车页面使用本地 Vue 库，不依赖外网 CDN
